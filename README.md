# 📊 Trabalho - API do GitHub

## 👨‍💻 Descrição

Este projeto foi desenvolvido como parte de um trabalho acadêmico com o objetivo de utilizar a **API REST do GitHub** para coletar, organizar e analisar informações de usuários e repositórios.

O projeto foi desenvolvido utilizando **Python**, com a biblioteca `Requests`, e os dados coletados foram organizados em um arquivo no formato **JSON**.

---

## 🎯 Objetivos

O trabalho tem como principais objetivos:

- Consultar informações de um usuário do GitHub;
- Listar os repositórios públicos do usuário;
- Calcular o total de estrelas dos repositórios;
- Analisar projetos open-source;
- Consultar estrelas, forks e issues abertas;
- Identificar as linguagens utilizadas nos projetos;
- Coletar dados de múltiplos repositórios;
- Criar um dataset no formato JSON;
- Gerar estatísticas básicas a partir dos dados coletados.

---

## 🛠️ Tecnologias utilizadas

- **Python**
- **GitHub REST API**
- **Requests**
- **JSON**
- **GitHub**
